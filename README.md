# 📄 AI Document Analyst (RAG System)

A full-stack AI application that allows users to upload PDF documents and ask questions based on the document's content. Built using Advanced RAG (Retrieval-Augmented Generation) architecture.

## 🚀 Features
* **PDF Processing:** Securely upload and process PDF documents.
* **Smart Context Retrieval:** Uses ChromaDB for highly accurate vector search.
* **Lightning Fast LLM:** Powered by Groq (Llama 3) for instant AI responses.
* **Interactive UI:** Clean, responsive chat interface built with Streamlit.

## 💻 Tech Stack
* **Frontend:** Streamlit
* **Backend:** FastAPI, Uvicorn
* **AI & NLP:** Groq API (llama3-8b-8192), HuggingFace Embeddings
* **Database:** ChromaDB (Vector Store)
